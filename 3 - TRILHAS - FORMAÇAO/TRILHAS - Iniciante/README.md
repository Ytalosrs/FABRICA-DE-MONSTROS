# 🚀 Trilha de Estudos para Iniciantes em Desenvolvimento de Software

## 📖 Sobre a Trilha

Esta trilha foi desenvolvida para orientar pessoas que desejam ingressar na área de tecnologia, proporcionando uma jornada de aprendizado estruturada, desde os fundamentos da computação até o desenvolvimento de aplicações completas.

Ao longo das fases, o estudante desenvolverá conhecimentos em programação, banco de dados, versionamento de código, documentação e boas práticas, criando projetos que poderão compor seu portfólio profissional.

---

# 🎯 Objetivos da Trilha

- Compreender os fundamentos da computação e da programação;
- Desenvolver o raciocínio lógico;
- Aprender Python do básico ao intermediário;
- Resolver problemas por meio de desafios práticos;
- Aprender modelagem e manipulação de bancos de dados relacionais;
- Utilizar Git e GitHub para versionamento de código;
- Desenvolver projetos completos;
- Criar documentação técnica;
- Construir um portfólio para demonstrar habilidades.

---

# 👨‍💻 Público-alvo

Esta trilha é indicada para:

- Pessoas sem experiência em programação;
- Estudantes iniciantes;
- Pessoas em transição de carreira;
- Interessados em desenvolvimento de software.

**Pré-requisitos:** Nenhum.

- Cadastro de usuários;
- Cadastro de livros;
- Controle de empréstimos;
- Registro de devoluções;
- Histórico de empréstimos;

### 🛠️ Tecnologias Utilizadas

- Python;
- MySQL;
- MySQL Workbench;
- Git;
- GitHub;
- Draw.io;
- Visual Studio Code.

### ✅ Resultado Esperado
